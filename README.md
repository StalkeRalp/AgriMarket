# AgriMarket — préparation du projet

## État actuel

Ce dépôt contient actuellement une base marketplace fonctionnelle héritée du projet ITEXAL Beauty. La structure et la logique applicative sont exploitables pour préparer la migration vers AgriMarket.

## Objectif de cette phase

Cette phase vise à :
- analyser le projet existant sans le casser,
- préserver l’interface actuelle,
- nettoyer les éléments inutiles uniquement si c’est clairement justifié,
- préparer la base pour la transformation progressive vers une marketplace agropastorale.

## Vérification

Le projet a été validé avec :

```bash
npm run build
```

Le build passe correctement.
